# ASTRALX Studio site

The public showcase site: `index.html` (home) and `samples.html` (Samples tab),
with sample pages in `samples/` and downloadable PDFs in `pdf/`.

## Publish on GitHub Pages

1. Create a free GitHub account and a new public repository named
   `astralxstudio.github.io` (use your GitHub username in place of `astralxstudio`).
2. On the repository page choose **Add file → Upload files** and drag in everything
   in this folder (keep the `assets`, `samples` and `pdf` folders as they are).
3. Commit. After a minute the site is live at `https://<username>.github.io`.
4. To update later, upload the changed files again the same way.

## Keep out of this folder

- The `private` folder next to this one (clip briefs and prompts).
- Large video files. Upload videos to YouTube (unlisted) or the Fiverr gallery and
  link to them instead.
